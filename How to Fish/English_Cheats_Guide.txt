============================================================
           Game Developer Cheat Mode Guide
============================================================

[REQUIREMENTS]
1. ClientSettings.CheatsEnabled must be set to True.
2. You must be the Host of the session.

------------------------------------------------------------
1. HOTKEYS (Instant Actions)
------------------------------------------------------------
[T] Key       - Time Scale: Cycles through [Normal / 0.1x / 0.01x]. Not Work
[O] Key       - Teleport & Skip: Skips to the next island in build.
[G] Key       - Damage Test: Reduces Health and Fullness instantly.
[H] Key       - Heal Test: Restores Health and Fullness to maximum.
[,] Key       - Toggle UI: Hides or Shows the tutorial UI group.
[Space] Key   - Infinite Jump: Requires /godmode active.

------------------------------------------------------------
2. CONSOLE COMMANDS (Type in Chat)
------------------------------------------------------------
/godmode         - Invincibility & Enables Mid-air Jumping.
/oneshot         - One-hit kill mode.
/addmoney        - Instantly adds money.
/nextisland      - Skips to the next island.
/killboss        - Instantly kills the current Boss.
/spawn <name>    - Spawns item/creature (See complete list below).
/spawndead <name>- Spawns a dead version of the creature.
